# v0.2.0 - protected areas

> **Upgrading from 0.1.2:** just replace the jar. Placed ropes, items and config carry over.

- **Ropes respect protection plugins.** Towny, WorldGuard, GriefPrevention, Lands and similar
  plugins now decide where ropes can go. A player can only break a rope if they're allowed to break
  every block of it, and a rope they place or shoot stops at the first block they aren't allowed to
  build in. The unused length comes back as rope coils.

- **No more lost rope.** A rope arrow whose rope is cut short now drops the unused length as coils
  instead of losing it, and a rope coil refund is dropped on the ground if the player logged out
  while the rope was still unrolling.

- **Rope arrows don't destroy blocks.** An arrow that flies through a torch, sign, button or similar
  no longer replaces it with a fence. It drops the rope coil instead. An arrow landing on top of a
  block with nothing above it to hang from now drops the coil too, rather than leaving a lone fence.

- **Adventure mode** players can no longer place or break ropes, matching how adventure mode treats
  other blocks.

- **Better help.** `/ropes` and `/ropes help` show the version, a short description, the commands
  you can use (admin commands are hidden from players without permission, in tab completion too),
  and links to the GitHub repo and the Discord. `/ropes delete_all` now says that it only removes
  ropes in loaded chunks.

- **Tested on Minecraft 26.x.** Every change is now checked on Paper and Purpur 1.21.11, 26.1.2,
  26.2 and 26.3.

**Note for servers running logging or anti-cheat plugins:** Ropes asks the server for permission one
block at a time, the same way a player placing or breaking that block would. Logging plugins like
CoreProtect may record those checks as block changes, and anti-cheat plugins like NoCheatPlus may
flag very long ropes placed in one go.
